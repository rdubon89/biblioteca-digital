# 📚 Biblioteca Digital

Sistema web administrativo desarrollado en **ASP.NET Web Forms + ASP.NET Web API** con autenticación JWT, control de roles, carga de archivos y arquitectura desacoplada.

---

# 🚀 Tecnologías utilizadas

## Backend
- ASP.NET Web API (.NET Framework)
- C#
- JWT Authentication
- SQL Server
- Stored Procedures
- ADO.NET
- HttpClient

## Frontend
- ASP.NET Web Forms
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- HTML5 + CSS3

## Base de datos
- SQL Server
- Arquitectura basada en Stored Procedures
